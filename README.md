# СметаAI

AI-калькулятор строительной сметы. Опишите проект на обычном языке — приложение соберёт смету, разбитую по разделам: **фундамент, стены, кровля, инженерные сети, отделка** и прочие работы. Любую позицию (объём и цену) можно поправить под свои реальные расценки — итог пересчитывается на лету.

Проект для хакатона **HackAlem AI**.

## Возможности

- Смета по 6 разделам с детализацией по позициям: наименование, объём, единица, цена, сумма.
- Автоматический расчёт объёмов из параметров проекта (площадь, этажность, материалы, регион, уровень отделки).
- **ИИ-режим:** описание проекта словами → параметры сметы через OpenAI. Без ключа работает встроенный офлайн-парсер.
- Редактирование любой позиции, добавление и удаление строк, живой пересчёт итогов.
- Диаграмма распределения затрат по разделам и стоимость за м².

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

Сборка продакшн-версии:

```bash
npm run build
npm run preview
```

## ИИ-режим (OpenAI)

Без ключа приложение полностью работает — описание разбирает встроенный парсер. Чтобы включить умный разбор через OpenAI:

1. Скопируйте `.env.example` в `.env`.
2. Впишите ключ: `VITE_OPENAI_API_KEY=sk-...`
3. Перезапустите `npm run dev`.

> **Важно:** сейчас ключ вызывается прямо из браузера — это удобно для прототипа, но для продакшна вынесите вызов OpenAI на бэкенд, чтобы ключ не попадал к пользователю.

## Как считаются объёмы

Движок оценивает объёмы работ параметрически. Основные допущения: высота этажа 3 м; периметр берётся от площади застройки (общая площадь ÷ этажность); площадь кровли — с коэффициентом на уклон и свесы. Базовые цены умножаются на региональный коэффициент, коэффициент материала стен и кровли, а также уровень отделки. Вся логика — в `src/lib/estimate.js` и `src/data/pricing.js`; правьте формулы и расценки под свои данные.

**Это предварительная смета.** Базовые цены усреднены по рынку Казахстана и требуют калибровки. Инструмент не заменяет сметный расчёт по нормативам (ГЭСН / сборники) для официальной документации.

## Структура

```
src/
  App.jsx              — сборка интерфейса и состояние
  data/pricing.js      — расценки, коэффициенты, списки материалов
  lib/estimate.js      — движок расчёта сметы
  lib/parseProject.js  — разбор описания: OpenAI или офлайн-парсер
  lib/format.js        — форматирование чисел и валюты
  components/
    Controls.jsx       — ввод описания и параметров
    Overview.jsx       — сводка и диаграмма
    CategoryCard.jsx   — раздел с редактируемыми позициями
```
